# Object-Oriented Design

This category teaches agents to design object-oriented systems around responsibilities, contracts, encapsulation, variation, collaboration, and controlled coupling.

The skills are intentionally behavioral rather than a catalog of OO vocabulary. Patterns and mechanisms such as inheritance, composition, delegation, polymorphism, and interfaces are treated as tools selected in context.

## Skills

1. `OO-01` Assign Responsibilities to the Right Object
2. `OO-02` Encapsulate Representation
3. `OO-03` Program to Abstractions
4. `OO-04` Encapsulate What Varies
5. `OO-05` Prefer Composition for Behavioral Reuse
6. `OO-06` Use Inheritance Only for Genuine Subtyping
7. `OO-07` Use Polymorphism to Localize Variation
8. `OO-08` Separate Collaboration from Implementation
9. `OO-09` Keep Object Responsibilities Cohesive
10. `OO-10` Minimize Object Coupling
11. `OO-11` Design for Replaceability

## Source synthesis

Primary sources are *Design Patterns: Elements of Reusable Object-Oriented Software* and *Head First Design Patterns*. *Clean Architecture* supplies dependency inversion, polymorphism, and boundary-oriented reasoning; *Code Complete* supplies cohesion, interface, coupling, complexity, and maintainability concerns.
