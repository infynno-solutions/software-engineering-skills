## Source synthesis
Clean Architecture (SOLID, component cohesion/coupling, dependency direction) + Code Complete (cohesion/coupling, information hiding, simplicity) + GoF/Head First (composition, interfaces, reuse) + Refactoring (evolutionary improvement).

## Agent usage
Load individual skills when their problem class is present. Prefer diagnosis first, then the minimum justified intervention, and always verify the result.
